練習セッション

1回の練習ごとの記録です。正解の行で「👋 おうちのひとがヒント」を押すと、外部ヒントありとして記録を直せます（ヒントなし成功には数えなくなります）。

「最近の反応時間」は直近3回の平均（参考値）。聞き取り直しを含むため、セッション記録の実測を優先してください。

音声認識テスト

🧪 動作テストモード

ONのあいだは、音声認識・読み上げ・判定・効果音・画面遷移は通常どおり動きますが、学習記録・成長・反応時間・練習履歴には一切加算しません。子ども画面の右上に小さく 🧪 が出ます。

設定

ON のあいだだけ、認識した文字や時刻などの開発用ログを、このタブの中に一時的に保存します（タブを閉じると消えます。どこにも送信しません）。

この端末の記録について

・練習の記録は、この端末のこのブラウザの中だけに保存されます（ログインなし）。ほかの端末やブラウザとは同期しません。
・ブラウザの「閲覧データの削除」をすると記録も消えます。iPad・iPhone では、Safari で開いたときとホーム画面から開いたときで記録が別になります。
・このアプリは、音声や認識した文字を独自のサーバーへ送りません。ただし声を文字にする処理は、ブラウザの音声認識（Chrome は Google、Safari は Apple）が各社のサーバーで行います。
・記録には、聞き取れなかったときに認識された文字（例：「聞き取れず「…」」）や本番暗唱の認識結果も含まれます。不要になったら下の「成長記録をリセット」で消せます。

端末を変えるときや、ローカル版（localhost）から公開版へ移るときに使います。読み込むと、この端末の今の記録はファイルの内容に置きかわります。

🛠 開発用：音の切り分け（「ピコン」音の調査）

「ピコン」が、アプリの効果音なのか、Android 等が音声認識の開始・終了で鳴らす音なのかを確かめます。テスト中は話さず、音が鳴ったときに下の記録と時刻を見比べてください。

練習中のマイクの開始・終了のまとめ（生ログから）

🛠 開発用：テンポ計測

子ども画面には出ません。学習記録とは別で、このタブを閉じると消えます。

計測中（約30秒）は声を出さないでください。読み上げを自分のマイクが拾ったかどうかも一緒に確認します。

🛠 開発用：マイク受付方式の比較（5の段の調査用）

「じゅんばんに 9もん」などの練習で、マイクをいつ・どの設定で開くかを切り替えます。切り替えたあと、同じ人が同じように答えて結果を比べてください。

問題ごとのタイムライン（読み上げ・マイク・認識結果・判定を同じ時間軸で）

🛠 開発用：音声認識の生ログ

Chrome が実際に返した文字列・候補・確信度と、アプリがどう数に直して判定したかを1件ずつ残します（子ども画面には出ません。このタブを閉じると消えます）。
「しじゅう」が受け付けられないときは：結果が来ていない → A、別の文字列で来ている → B、文字列は来ているのに判定が C/B → C（アプリ側の正規化）と切り分けられます。
